## Permanent hosting (Render — recommended)

1. Push `main` (includes `render.yaml` + `deploy/Dockerfile`).
2. Open [Render Blueprints](https://dashboard.render.com/blueprints) → **New Blueprint Instance**.
3. Connect GitHub repo `ahsanidreesnns8-ai/Arhat-Management-System-`, branch `main`.
4. Apply the Blueprint. Render builds the all-in-one Docker image.
5. Your site will be at `https://arhat-erp.onrender.com` (or the name shown in the dashboard).
6. Change the default owner password immediately after first login.

### Environment variables (Render)

| Variable | Required | Notes |
|----------|----------|-------|
| `JWT_SECRET` | Yes | Auto-generated by Blueprint |
| `CORS_ALLOWED_ORIGINS` | Yes | `*` for single-host image |
| `GEMINI_API_KEY` | Optional | AI assistant |

## Docker Compose (VPS)

```bash
cp .env.example .env
# edit JWT_SECRET and passwords
docker compose up -d --build
```

| Service | URL |
|---------|-----|
| UI | http://YOUR_SERVER:5173 |
| API | http://YOUR_SERVER:8080/api |

Single-container production image:

```bash
export JWT_SECRET='your-long-random-secret'
docker compose --profile prod up -d --build arhat
# App: http://YOUR_SERVER/
```
